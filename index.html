Before you start

先理解服务，再开始配置。

Thuban 的不同套餐对应不同的流量额度、在线设备数与服务方向。选择之前，先判断自己属于个人使用、多设备使用，还是需要团队协作的场景。

选择原则

不要只看流量数字，也要看同时在线设备数。

如果你的使用场景集中在个人手机、电脑与少量平板，基础版更轻量；经常在多台设备之间切换，可以关注旗舰版；涉及多人共同使用或定制路由需求，则可进一步了解团队版。

配置顺序

从确认系统开始，到导入配置结束。

先确认设备操作系统，再选择与当前系统匹配的客户端。完成后检查基础网络是否可用，再导入对应配置，可以减少重复排查。

STEP 01

确认设备与系统

记录准备接入的设备数量，以及每台设备所运行的系统环境。

STEP 02

选择对应套餐

结合流量周期、设备数量及服务需求，对照套餐权益进行选择。

STEP 03

安装并检查配置

从可信渠道取得客户端与配置，完成导入后再测试常用页面是否正常。

Clients

客户端选择，保持简单。

客户端应与设备系统相匹配。由于页面不提供未经确认的下载地址，请通过可信任的服务入口获取对应安装包与配置文件，避免安装来源不明的软件。

Windows 客户端

适用于运行 Windows 系统的电脑。安装后先检查系统代理设置，再导入配置并逐步验证。

核对系统版本 → 获取安装包

适用于 Mac 电脑。首次启动时，根据系统提示确认必要的网络权限与辅助权限设置。

移动端客户端

适用于手机与平板。根据实际系统版本选择对应客户端，并留意应用来源是否可靠。

确认系统 → 选择应用

Configuration note

配置完成后，按这个顺序检查。

第一步：确认客户端能够正常启动，并显示当前已载入的配置状态。

第二步：检查系统代理或相关网络权限，避免出现客户端已连接但流量未按配置转发的情况。

第三步：逐步打开常用页面进行测试。如果出现异常，可先切换其他可用配置，再记录设备、系统、客户端版本与发生时间，方便后续定位。

第四步：当需要新增设备时，先核对当前套餐允许的同时在线设备数，再进行配置。

FAQ

常见问题，直接回答。

关于套餐、设备数量与客户端配置，先通过以下问题完成初步判断；涉及购买和实际连接时，仍应以当时可访问的服务信息为准。

基础版、旗舰版和团队版应该如何选择？

主要根据同时在线设备数和具体需求判断。个人多设备使用可关注旗舰版；多人共同使用、需要企业定制路由或更高在线设备数时，可查看团队版。

月付和年付有什么区别？

页面列出的年付金额对应一个完整服务周期，月付则按月展示。基础版为 ¥15/月或 ¥150/年，旗舰版为 ¥35/月或 ¥350/年，团队版为 ¥85/月或 ¥850/年。

客户端应该从哪里下载？

请从实际可访问且可信的服务入口获取与你的系统匹配的客户端及配置。本页不提供未经确认的下载地址，也不建议安装来源不明的安装包。

导入配置后没有立即生效，应该先检查什么？

先确认客户端是否正常启动、配置是否成功载入，再检查系统代理或相关权限是否开启。仍有问题时，可切换其他可用配置，并记录设备系统、客户端版本与异常发生时间。

增加设备前需要注意什么？

先核对套餐允许的同时在线设备数。基础版为 3 台，旗舰版为 5 台，团队版为 20 台，避免在不了解当前套餐的情况下重复添加配置。

页面列出的权益是否代表实时服务状态？

不一定。套餐权益用于帮助比较方案，实时连接状态、节点可用性、购买与续费信息应以来源可靠的服务页面及当前配置为准。
